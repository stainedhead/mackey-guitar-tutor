# src-tauri/icons

Placeholder app icons (a simple neck on a dark tile) listed in `tauri.conf.json` `bundle.icon`: `32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.png`, `icon.icns` (macOS) and `icon.ico`. They were produced with `npx tauri icon <1024px source.png>`; replace them the same way when real artwork exists. Windows tiles and Android assets that the tool also emits are deleted because those platforms are deferred, and `tauri ios init` generates the iOS asset catalogue.

Part of [`src-tauri`](../README.md).
