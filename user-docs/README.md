# user-docs

Guides for people using Mackey Guitar Tutor on a Mac or iPad. Screenshots are of the real app; see [docs/images](../docs/images/README.md) for how they were made. For product and engineering docs see [../docs/](../docs/README.md).

| File | Purpose |
|---|---|
| [getting-started.md](getting-started.md) | Build and install from source on a Mac, first launch, a five-minute tour |
| [explorer.md](explorer.md) | Explore: keys, chords, voicings, triads, arpeggios, scales, cycling, shortcuts, left-handed, tunings and capo |
| [tuner.md](tuner.md) | The tuner: microphone, chromatic and string modes, reference tones |
| [settings.md](settings.md) | Every setting, its default and where it is stored |
| [troubleshooting.md](troubleshooting.md) | Gatekeeper, microphone permission, no sound, a corrupt settings file |

Practice sessions, songs and rhythm are designed ([docs/roadmap.md](../docs/roadmap.md)) but not built yet, so they have no guide. Back to the [root README](../README.md).
