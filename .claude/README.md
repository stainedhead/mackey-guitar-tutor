# .claude

Claude Code project settings.

| File | Purpose |
|---|---|
| `settings.json` | Registers the `stainedhead/shared-plugins` marketplace and turns on the `dev-flow` and `repo` plugins, so the commands listed in [AGENTS.md](../AGENTS.md) are available as `/dev-flow:<name>` and `/repo:<name>` in every session for this repo, including cloud sessions |

Personal overrides go in `settings.local.json`, which git ignores. Back to the [root README](../README.md).
